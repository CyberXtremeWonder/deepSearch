# 药品库存清单（库存量 > 100，按库存量升序）

- 数据来源：`deepsearch_db.inventory` JOIN `deepsearch_db.drugs`
- 筛选条件：`quantity_on_hand > 100`
- 排序：库存量升序
- 命中记录数：150

## 执行的 SQL

```sql
SELECT d.generic_name              AS 药品名称,
       i.batch_number              AS 批次号,
       i.warehouse_location        AS 仓库位置,
       i.expiry_date               AS 过期日期,
       i.quantity_on_hand          AS 库存量
FROM deepsearch_db.inventory i
JOIN deepsearch_db.drugs d ON i.drug_id = d.drug_id
WHERE i.quantity_on_hand > 100
ORDER BY i.quantity_on_hand ASC;
```
